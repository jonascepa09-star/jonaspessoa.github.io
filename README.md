## Publicar no GitHub Pages
Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**.

Endereço previsto: https://jonascepa09-star.github.io/jonaspessoa.github.io/

O nome do repositório é diferente do nome da conta; por isso, será publicado como **site de projeto**.
